# 2026-10-19 实验方向总览

今天的工作有源码、测试和技术报告记录，但没有形成可切默认的统一优化。RDOQ在已测近似码率下有平均收益，同时存在尾部风险；两次局部预算修复未采用；统一预算原型通过实现/合同检查，后续一次固定强度匹配仍有一个输入失配，因此两素材的同码率效率结论未定。SDK未发布，默认保持原行为。

## 共同边界与比较口径

以下直播质量实验主要是已有HEVC 1080p60、GOP120输入，经paced loopback RTMP进入服务，输出960×540p30、10-bit VVC。不能称为1080p输出容量、实际部署等价或source-to-screen时延验证。视频码率口径为AVPacket payload加首次codec configuration，不含音频/容器/RTMP开销；时延计至实际mux/write/flush，含排队。

RDOQ工具对照、旧控制器对照、统一控制器和固定质量强度匹配是不同窗口。各自使用对应源码/二进制/SDK、输入和PTS绑定；不能串成同一对照。数值为本地有限样本，均值、绝对低分、连续损失和码率匹配须同时看。单个负帧不等于整体画质下降，码率未匹配也不等于四类硬合同失败。

RDOQ自然内容续测另有一次固定实际slice-QP的局部诊断：定位帧的差值由历史−17.797变为约+3.945，但对应17帧窗口bits增加约9.613%。这是局部诊断，不是同码率工具收益、控制器修复或其余负帧已解决。

自然内容续测的pooled PSNR差分别约为树林+0.102/+0.098dB、城市+0.062/+0.063dB（full/selective）。这些平均收益保留；上述尾部风险也保留，不将两种观察互相替代。

## 原型与探索的明确限制

- 默认`NAKI_UNIFIED_RATE`关闭、bias为0；固定匹配值仅用于显式实验。没有将40%份额或单独预留候选提升为默认。
- 统一策略与固定bias改变有效质量强度；预测和学习使用最终请求QP。预算求解、信用和学习规则未改，真实反馈仍正常改变后续系数、历史及quota，没有冻结旧轨迹。
- bias来自同两份旧素材的整数阈值解析；小数位数不表示实测调参精度。本轮是探索、非盲测，不建立泛化能力，也不追认此前筛选通过。
- CVaR1取最低`ceil(1%×N)`帧的算术平均；PTS持续时长、连续退化、普通I/活动RPL后代的筛选在运行前冻结于[判据JSON](unified-match-criteria-20261019.json)。活动RPL不是逐CTU实际使用轨迹或质量因果隔离。
- 本轮没有实现新的入流平滑器或其与编码器反馈的节奏联动，没有开展ALF/CCALF恢复、吞吐/容量优化、长期稳定性或部署替代验收。性能仅作对应单次运行的描述。
