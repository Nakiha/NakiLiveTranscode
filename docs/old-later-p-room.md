# Opt-in OLD later-P room experiment

This isolated candidate is based on e076ada. Default is off; only explicit
`NAKI_OLD_LATER_P_ROOM=1` in a constrained-CRF worker enables it. Other accepted
value is0; an unset variable is off. The pipeline_ready event identifies enabled
mode. This is a process experiment setting, not an HTTP update or production claim.

Only later predicted P uses the full existing pending-adjusted95% soft room,
instead of40%. The original nominal target still caps the allowance. The old
floor cannot lift this P above room; an infeasible integer prediction fails
before reservation. First-P85%, B40%, I protection, clocks, models, actual
feedback/write accounting, scheduling and encoder tools remain unchanged.

The removed60% was implicit headroom for unsubmitted pictures. Its removal can
transfer pressure to B or cause selection failures. OLD has no hard token-credit
ledger; existing source/absolute buckets and wall/DTS rolling limits still require
independent measurement. Prediction boundedness is not actual contract conformance.

The supplied historical state selects requestQP45/prediction24194 within25775bit
room. Request44 would predict27156 and cannot fit. These values are only a unit
fixture; no frame index or QP is hardcoded in policy.

The local unit review passed legacy cases, first-P/B/I parity,960 bounded-room
cases, real actual feedback, numeric bounds, ASan/UBSan/float-cast-overflow and
caller syntax. The authorized media screen is exactly forest30 and urban12,
each once off/on on the same frozen binary and unchanged input/tools/CRF. Any
media or hard-contract failure stops the screen; no parameter scan or bias.
Quality must report all frames, rate matching, absolute low tails, sustained
losses and B pressure. No SDK or public push is part of this experiment.
